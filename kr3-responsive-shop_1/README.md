## О проекте

ShopProject — многостраничный каталог канцтоваров. За основу взят HTML/CSS-проект контрольной работы №1, Bootstrap и другие CSS-фреймворки не используются. Адаптивность реализована с помощью Flexbox, Grid, CSS-переменных и медиазапросов. Формы демонстрационные: введённые данные не отправляются на сервер.

## Адаптивные решения

- Стили распределены по назначению: основной дизайн в `style.css`, Mobile First в `responsive.css`, настройки фокуса и контраста в `accessibility.css`. Порядок подключения одинаков на всех страницах.
- На мобильных экранах верхняя навигация сворачивается в меню с кнопкой «Меню»; состояние объявляется через `aria-expanded`. Без JavaScript ссылки остаются доступными.
- Каталог использует одну колонку на телефонах и перестраивается по ширине экрана. Фильтр на небольших экранах открывается отдельной кнопкой, а на широких остаётся боковой панелью. Фильтрация учитывает категорию, цену и наличие; предусмотрено сообщение, когда товары не найдены.
- Блок преимуществ, карточки товаров, панель главного экрана, форма и контакты адаптируются через Grid и Flexbox без фиксированных ширин, выходящих за экран.
- Таблица на мобильных экранах до 639 px отображается как карточки «Параметр — Значение — Комментарий»; с 640 px возвращается обычная таблица. Заголовки строк и столбцов сохранены в HTML.
- Для шести товаров подготовлены изображения JPG и WebP разных размеров. В карточках используется `<picture>` с `srcset` и `sizes`, `loading="lazy"` и заданными исходными размерами.
- Модальное окно учитывает высоту мобильного экрана и остаётся доступным при управлении с клавиатуры.

## Доступность

- Семантические элементы `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, один `h1` на страницу.
- Ссылка «Перейти к содержимому», `aria-current="page"`, `aria-expanded` для раскрывающихся панелей.
- Видимый `:focus-visible`, контрастные подписи, сообщения об ошибках, поддержка `prefers-reduced-motion`.
- У всех изображений есть осмысленные `alt`, у полей форм — `label`; ошибки связаны с полями с помощью `aria-describedby` и `aria-invalid`.
- Диалог реализован нативным `<dialog>` с заголовком `aria-labelledby`, кнопкой закрытия и поддержкой Escape.

## Проверка

Для ручной проверки в DevTools предусмотрены размеры **360, 430, 768, 1024 и 1440 px**. На каждой ширине необходимо просмотреть все пять страниц, меню, карточки товаров, модальное окно, форму, таблицу и убедиться, что нет горизонтальной прокрутки всей страницы. Переключение размеров можно использовать для проверки `picture` и `srcset` на вкладке Network → Img.

В папке `lighthouse/` сохранены исходные скриншоты Lighthouse, полученные во время практической №13. Результаты проверки категории Accessibility на момент создания этих отчётов:

| Страница | Accessibility |
| --- | ---: |
| `index.html` | 100/100 |
| `catalog.html` | 100/100 |
| `order.html` | 100/100 |

После любых изменений кода Lighthouse следует запускать повторно. Автоматический аудит не заменяет проверку навигации с клавиатуры, работы модального окна и форм.

## Запуск

Откройте каталог проекта в Visual Studio Code, запустите Live Server и перейдите на `index.html`. Дополнительная сборка не требуется.
