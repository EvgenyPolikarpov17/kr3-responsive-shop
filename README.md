# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание

ShopProject — адаптивный учебный интернет-магазин канцтоваров, созданный на основе HTML/CSS-проекта контрольной работы №1. Для адаптивности используются CSS Grid, Flexbox и медиазапросы без Bootstrap.

## Практическая работа №12

Выполнено:

- создан отдельный проект `kr3-responsive-shop` на основе КР №1;
- добавлен и подключён на всех страницах файл `css/responsive.css` после `css/style.css`;
- проверен тег `viewport`;
- применён подход Mobile First и медиазапросы `min-width`;
- адаптированы шапка, навигация, hero-блок, сетки карточек и каталог с фильтром;
- добавлены изображения различных разрешений с `srcset` и `sizes`;
- использован `picture` с WebP и JPEG на странице товара;
- адаптированы форма заявки, таблица характеристик, модальное окно и фиксированная кнопка;
- предусмотрены размеры экранов 360px, 430px, 768px, 1024px и 1440px.

## Проверка

1. Открыть `index.html` через Live Server в VS Code.
2. Открыть DevTools → Toggle device toolbar.
3. Проверить каждую страницу на ширинах 360px, 430px, 768px, 1024px и 1440px.
4. Убедиться, что отсутствует горизонтальная прокрутка страницы; проверить адаптивные изображения в Network → Img.
5. Проверить форму, таблицу и модальное окно.

## Самостоятельные доработки

### 1. Собственные разделы и компоненты

Добавлены:

- блок «Как оформить заявку»;
- FAQ через `details` и `summary`;
- расширенный footer;
- информационный блок «После заявки»;
- карточки контактов;
- дополнительный блок преимуществ товара.

### 2. Собственное визуальное оформление

Использована единая система CSS-переменных для:

- цветов;
- отступов;
- скруглений;
- поверхностей;
- состояний компонентов.

Главная страница, каталог, карточка товара, форма и контакты оформлены в едином стиле.

### 3. Улучшенные карточки товаров

Добавлены:

- бейджи «Хит», «Новинка», «−20%», «Нет в наличии»;
- категории;
- рейтинг;
- состояние наличия;
- старая цена для товара со скидкой;
- модификаторы карточек.

### 4. Доработанный пользовательский сценарий заявки

Реализованы:

- отдельная страница `order.html`;
- быстрая заявка через `<dialog>` на главной странице;
- автоматическое отображение выбранного товара;
- сообщение об успешном заполнении;
- подсказка по формату телефона;
- визуальное состояние ошибки через `aria-invalid`.

### 5. Улучшенная навигация и каталог

Добавлены:

- хлебные крошки;
- sticky-шапка;
- sticky-фильтр;
- фиксированная кнопка «Оставить заявку»;
- ссылка «Наверх»;
- статические фильтры по категории, цене и наличию.

### 6. Доступность

Используются:

- `skip-link`;
- `aria-current`;
- `aria-label`;
- `aria-labelledby`;
- `aria-describedby`;
- связки `label` + `for`;
- `alt` у изображений;
- `scope` в таблице;
- заметный `:focus-visible`;
- понятные состояния элементов.

### 7. Последовательный БЭМ

Примеры блоков:

- `site-header`;
- `site-nav`;
- `breadcrumbs`;
- `product-card`;
- `catalog-filters`;
- `filters-form`;
- `product-details`;
- `product-table`;
- `order-dialog`;
- `order-form`;
- `site-footer`.

## Где показано позиционирование

- `position: relative` — карточка товара и визуальный блок страницы товара;
- `position: absolute` — бейджи;
- `position: sticky` — шапка и фильтр каталога;
- `position: fixed` — skip-link и кнопка «Оставить заявку»;
- `z-index` — шапка, бейджи и фиксированные элементы.

## Как запустить

Можно открыть `index.html` напрямую в браузере.

Также можно открыть папку проекта в Visual Studio Code и запустить `index.html` через Live Server.
